# Icons

Lucide 0.468.0: `text`, `asterisk`, `regex`, `folder-tree`, `search`, `square`.
The pattern-mode buttons use `text` (Literal), `asterisk` (Glob) and `regex` (RegEx).
Source: https://github.com/lucide-icons/lucide/tree/0.468.0/icons
Only SVG whitespace is condensed.
License: [ISC](LICENSE.txt).

[panel-left.svg](panel-left.svg) and [panel-right.svg](panel-right.svg) are
custom geometric versions of Unicode U+25E7 and U+25E8, the half-filled squares
used by [StatusBarExtended](https://github.com/kek91/StatusBarExtended).
They use square corners and a solid left/right half, rendered at 20 logical
pixels without depending on font glyph size. The host applies the current
palette color to all icons except the red Stop icon.
