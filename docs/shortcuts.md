# Keyboard Shortcuts

Open the Command Center with ++ctrl+shift+p++ to see every command.

## Files

| Key | Action |
| --- | --- |
| ++f3++ | View file |
| ++f4++ | Edit file |
| ++shift+f4++ | Create and edit file |
| ++ctrl+n++ | Create empty file |
| ++f5++ | Copy |
| ++f6++ | Move |
| ++shift+f6++ | Rename |
| ++f7++ | Create folder |
| ++f8++ or ++delete++ | Move to Recycle Bin |
| ++shift+delete++ | Delete permanently |
| ++f11++ | Copy path |

## Navigation

| Key | Action |
| --- | --- |
| ++tab++ | Switch panes |
| ++enter++ | Open |
| ++backspace++ or ++alt+up++ | Go up |
| ++alt+left++ / ++alt+right++ | Back / forward |
| ++alt+f1++ / ++alt+f2++ | Choose a drive |
| ++ctrl+left++ / ++ctrl+right++ | Open in left / right pane |
| ++ctrl+r++ | Refresh |

## Selection and Display

| Key | Action |
| --- | --- |
| ++space++ | Toggle selection |
| ++ctrl+a++ | Select all |
| ++ctrl+d++ | Clear selection |
| ++ctrl+period++ | Toggle hidden files |
| ++ctrl+q++ | Toggle image QuickView |
| ++ctrl+s++ | Cycle status details |
| ++ctrl+shift+d++ | Toggle directory sizes |
| ++ctrl+shift+enter++ | Calculate selected directory size |

## Tools

| Key | Action |
| --- | --- |
| ++f9++ | Open terminal |
| ++f10++ | Open in Explorer |
| ++alt+f5++ | Pack archive |
| ++ctrl+b++ | Open Favorites |
| ++ctrl+h++ | Calculate file hash |

## Commander Style Shortcuts

For a Norton Commander or Total Commander style workflow.

| Key | Action |
| --- | --- |
| ++f1++ | Show keyboard shortcuts |
| ++f3++ | View file |
| ++f4++ | Edit file |
| ++f5++ | Copy |
| ++f6++ | Move |
| ++f7++ | Create folder |
| ++f8++ | Move to Recycle Bin |
| ++f9++ | Open terminal |
| ++f10++ | Open in Explorer |
| ++f11++ | Copy path |

++f2++ and ++f12++ are currently unassigned.
